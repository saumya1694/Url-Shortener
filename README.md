URL Shortener

A simple and responsive URL Shortener Web Application built using HTML, CSS, and JavaScript.
This project converts long URLs into short and shareable links using the TinyURL API.

🚀 Features

Shortens long URLs instantly

Copy shortened link to clipboard

Clean and responsive user interface

API integration using Fetch

Error handling for invalid inputs

🛠️ Technologies Used

HTML

CSS

JavaScript

TinyURL API
